## Présentation Réseau Kubernetes

````
 [User]
   |  (1) requête
   v
 +-----+                          +------+
 | DNS |------------------------->|  LB  |
 +-----+                          +--+---+
    |                                |  vers :32000 de chaque noeud
    | virtual hostname               |
    v                  +-------------+--------------+
 +------------------+  |             |              |
 |     Ingress      |  v             v              v
 +------------------+ +--------+  +--------+  +--------+
 | Ingress          | | Node 1 |  | Node 2 |  | Node 3 |
 | Controller       | | :32000 |  | :32000 |  | :32000 |
 +--------+---------+ +---+----+  +---+----+  +---+----+
          |               |           |           |
          |            ==== ext net (réseau externe) ====
          |               |           |           |
          |               +-----------+-----------+
          |                           |
          |                     cluster net  <---- api server
          |                           |
          |              +------------+------------+
          |              |                         |
          |        +-----+-----------+     +-------+---------+
          |        | svc NodePort    |     | svc ClusterIP   |
          |        +----+-----+------+     +----+-----+------+
          |             |     |                 |     |
          +------------------------------------>+     |
        (l'Ingress route vers le ClusterIP)           |
                      p1    p2    p3          p4    p5    p6
                      \_____|____/            \_____|____/
                            |                       |
          ==== pod net (réseau des pods, géré par le plugin CNI) ====
````
DNS         => résout le hostname vers l'IP du LB
LB          => répartit vers n'importe quel nœud sur le port NodePort
NodePort    => port ouvert sur CHAQUE nœud, redirige vers le ClusterIP
ClusterIP   => IP virtuelle interne, répartit vers les Pods
Ingress     => route HTTP/HTTPS selon le hostname ou le path vers le bon ClusterIP
CNI         => gère le réseau des Pods (Calico, Flannel...)
