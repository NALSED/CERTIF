## **Externe au Cluster**
- DNS         => résout le hostname vers l'IP du LB. Déclaration `A` `AAA` du service chez un provider ou on-promise.

- LB          => Répartit vers n'importe quel nœud sur le port NodePort. Chez un provider ou on-promise.


## **Interne au Cluster**

### `=== Objet Kubernetes ===`

`[NOTE]`
- Les services ne fonctiones pas seul ils sont imbriqués les un dans les autres pour pouvoir faire entrer /sortir du cluster
- En effet 


- Service :

   - ClusterIP   => IP virtuelle interne, répartit vers les Pods

   - NodePort    =>  port ouvert sur CHAQUE nœud, redirige vers le ClusterIP






   
- Ingress     => route HTTP/HTTPS selon le hostname ou le path vers le bon ClusterIP

- CNI         => gère le réseau des Pods (Calico, Flannel...)
