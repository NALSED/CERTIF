## API Access

---

### Vue d’ensemble du fonctionnement des `certificats` et `RBAC`

`=== Certificats ===`

- Chaque client de `kubernetes` (Tous ce qui parle à l'api server), utilise les certificats fournis et signés par le `CA` de kubernetes pour les `Authentifications` au sein du cluster.

- kubctl à accées aux certificats clients, et quand une requete est faites à `apiserver` ce dernier est capable de vérifier le certificat du client.

- Il est aussi possible de le faire avec `kube-proxy`, il agis comme un frontend et l'on peux alors intéroger les certificat via `curl` pour communiquer avec `kubernetes`.

`=== RBAC ===`

- Roles Base Access Control, definis les role et role bindings, pour leurs assigner des permissions .
