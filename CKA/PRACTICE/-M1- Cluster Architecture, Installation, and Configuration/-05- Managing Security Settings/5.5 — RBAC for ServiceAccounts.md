 ## RBAC => ServiceAccounts

 ---

 - Pour éditer les droits pour un `Service Account` (Compte qui permet à un service de se connecter au cluster) :
 
    -  Création d'un `Roles` (Droits)
    -  Création d'un `RoleBinding` pour faire le liens entre le `Roles et le `Service`.

- Tous les `Pods` on un `ServiceAccount` avec un accés minimal, mais pour des besoin spécifique un `ServiceAccount` dédié doit être créé.
