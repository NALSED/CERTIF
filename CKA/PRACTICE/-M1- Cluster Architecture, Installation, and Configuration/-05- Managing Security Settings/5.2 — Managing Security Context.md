## Présentation Security Context

---

[DOC](https://kubernetes.io/docs/tasks/configure-pod-container/security-context/)

- La configuration de `Security Context` passe par des fichier .yaml

- C'est une partie du fichier `.yaml`, avec pour entête `securityContext:`, les différente option sont disponible dans la doc ci-dessus.

- `Security Context` créé un héritage en `champs par champs` c'est à dire que si une régle est déffini dans la partie `pod` et `container`, la partie container prend le dessu sur la configuation du pod.
