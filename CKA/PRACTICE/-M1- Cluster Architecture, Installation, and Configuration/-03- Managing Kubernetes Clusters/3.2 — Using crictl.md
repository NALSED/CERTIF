## Présentation du client `crictl`

---

- `crictl` est un client pour parler directement au `CRI` donc containerd, sans passer par Kubernetes/l'API server.

- Il doit être implémenté `sur tous les nodes`

- Avant toute chose vérifier si `crictl` est présent sur la machine
````
crictl --version

# Si absent
sudo apt install -y cri-tools
````

- De base il n'est pas déclaré dans /etc, il convient de réaliser cette opération.
````
sudo vim /etc/crictl.yaml
````

- Éditer
````
runtime-endpoint: unix:///var/run/containerd/containerd.sock
image-endpoint: unix:///var/run/containerd/containerd.sock
timeout: 10
debug: true
# ICI => debug: true sur k8s-master
````

---

### === Commandes de bases ===

- La commande suivante montre les conteneurs (!! Tous sans distinction, ceux d'administration Kube et les applicatifs !!)
````
sudo crictl ps
# Il est possible de filtrer avec `label` `ns` ou `nom de pod`
````

- La sortie de `crictl` permet d'utiliser la commande `crictl inspect <n°CONTAINER>`
````
# Inspection de etcd
sudo crictl inspect 38e559c767db1

# En sortie un "cat" du fichier .json du conteneur concerné
````

- Lister toutes les sandbox par défaut
````
sudo crictl pods
````

- Lister les images en cache correspondantes aux conteneurs
````
sudo crictl images
````

- Les commandes ci-dessus peuvent être utilisées avec des options :

### === crictl ps ===
````
sudo crictl ps -a                               # inclut les arrêtés (pas que Running)
sudo crictl ps --name coredns                   # par nom de conteneur
sudo crictl ps --state running                  # running / exited / created
sudo crictl ps --label io.kubernetes.pod.namespace=kube-system
sudo crictl ps --pod <POD_ID>                    # conteneurs d'un pod précis
sudo crictl ps -q                                # IDs seuls (utile pour scripter avec xargs)
````

### === crictl pods ===
````
sudo crictl pods --name coredns
sudo crictl pods --state ready                   # ready / notready
sudo crictl pods --namespace kube-system
sudo crictl pods --label k8s-app=kube-dns
sudo crictl pods -q
````

### === crictl images ===
````
sudo crictl images --digests                     # affiche les digests SHA
sudo crictl images -q
sudo crictl images <repository>                  # filtre par nom, ex: sudo crictl images calico
````
