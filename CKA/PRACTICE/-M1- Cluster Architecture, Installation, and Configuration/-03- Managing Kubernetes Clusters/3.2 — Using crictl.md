## Présentation du client `crictl`

---

- `crictl` est une client pour parler directement au `CRI` donc containerd, sans passer par Kubernetes/l'API server.

- Il doit être implémenté `sur tous les node`

- Avant toute chose verifier si `crictl` est présent sur la machine
````
crictl --version

# Si abscent
sudo apt install -y cri-tools
````

- De base il n'est pas déclaré dans /etc, il conviens de réaliser cette opération.
````
sudo vim /etc/crictl.yaml
````

- Editer
````
runtime-endpoint: unix:///var/run/containerd/containerd.sock
image-endpoint: unix:///var/run/containerd/containerd.sock
timeout: 10
debug: true
````

---

- La commande suivant montre les container (!! Tous sans distinction !!)
````
sudo crictl ps
````

- Il est possible de filtrer avec `label` `ns` ou `nom de pod`
