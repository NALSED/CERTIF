## Présentation du client `crictl`

---

- `crictl` est une client pour parler directement au `CRI` donc containerd, sans passer par Kubernetes/l'API server.

- Il doit être implémenté `sur tous les node`

- Avant toute chose verifier si `crictl` est présent sur la machine
````
crictl --version

# Si abscent
sudo apt install -y cri-tools
````

- De base il n'est pas déclaré dans /etc, il conviens de réaliser cette opération.
````
sudo vim /etc/crictl.yaml
````

- Editer
````
runtime-endpoint: unix:///var/run/containerd/containerd.sock
image-endpoint: unix:///var/run/containerd/containerd.sock
timeout: 10
debug: true
# ICI => debug: true sur k8s-master
````

---

### === Commandes de bases ===

- La commande suivant montre les container (!! Tous sans distinction ce d'administration Kube et les applicatif !!)
````
sudo crictl ps
# Il est possible de filtrer avec `label` `ns` ou `nom de pod`
````

- La sortie de `crictl` permet d'utiliser la commande `crictl inspect <n°CONTAINER>`
````
# Inspection de etcd
sudo crictl inspect 38e559c767db1

# En sortie un "cat" du fichier .json su container concerné
````

- Lister toutes les sandbox par defaut
````
crictl pods
````

- Lister les images en cache corespondantes aux container
````
sudo crictl images
````

---

- Les commandes ci dessus peuvent être utilisées avec des options :

=== Options commandes ===
</h2>

### === crictl ps ===
````
crictl ps -a                                    # inclut les arrêtés (pas que Running)
crictl ps --name coredns                        # par nom de conteneur
crictl ps --state running                       # running / exited / created
crictl ps --label io.kubernetes.pod.namespace=kube-system
crictl ps --pod <POD_ID>                         # conteneurs d'un pod précis
crictl ps -q                                     # IDs seuls (utile pour scripter avec xargs)
````

### === crictl pods ===
````
crictl pods --name coredns
crictl pods --state ready                        # ready / notready
crictl pods --namespace kube-system
crictl pods --label k8s-app=kube-dns
crictl pods -q
````

### === crictl images ===
````
crictl images --digests                          # affiche les digests SHA
crictl images -q
crictl images <repository>                       # filtre par nom, ex: crictl images calico
````
