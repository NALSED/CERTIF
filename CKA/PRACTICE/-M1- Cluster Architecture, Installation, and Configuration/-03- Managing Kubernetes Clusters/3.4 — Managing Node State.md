## Gestion de base d'une node

---

### === CORDON ===

- Pour pouvoir `investiguer` sur un node il est utile de mettre en `quarantaine` le `node`

- Pour ce faire utiliser
````
kubectl cordon NODE NAME

# Sortie
node/k8s-worker1 cordoned
````

- Après mis en quarantaine le `node` deviens `SchedulingDisabled`, plus aucun pode ne pourra çtre créer pas le `Scheduler` sur `k8s-worker1`.

- On peu aussi constaté qu'un nouveau champs est apparu dans la sortie description de `k8s-worker1` => `Taints` 
````
kubelctl describe node k8s-worker1 | less
````
````
Taints:             node.kubernetes.io/unschedulable:NoSchedule
````

- Lorsque l'investigation est fini
````
kubectl uncordon NODE NAME

# Sortie
node/k8s-worker1 uncordoned
````

---

### === DRAIN ===

- Même effet de mise en quarantaine que `cordon`, et en plus suppression de tout les pods en cours
