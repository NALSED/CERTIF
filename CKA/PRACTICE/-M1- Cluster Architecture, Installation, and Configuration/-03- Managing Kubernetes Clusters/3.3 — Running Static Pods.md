## `Static Pods`

---

- Les `Statics Pods` sont défini ici : `/etc/kubernetes/manifests`

- Ils sont une `partie essentiel` du fonctionement de `Kubernetes` :
  
     - etcd.yaml
     
     - kube-apiserver.yaml
     
     - kube-controller-manager.yaml
     
     - kube-scheduler.yaml
 
- On peux ajouter des `Static Pods` en ajoutant un fichier .yaml dans de dossier, et kubelet se chargera de récupérer la nouvelle configuration et de l'appliquer.

- Pour changer le chemin par defaut de configuration des `Static Pods` editer le fichier `/var/lib/kubelet/config.yaml`
