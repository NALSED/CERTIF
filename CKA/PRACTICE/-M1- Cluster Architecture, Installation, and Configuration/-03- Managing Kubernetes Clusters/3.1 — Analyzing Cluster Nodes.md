=== Commande de base pour voir l'état d'un cluster ===

- `Node`
````
# Commande uniquement sur le master
kubectl describe node k8s-master
````

- `Kubelet => journalctl`
````
journalctl -u kubelet
sudo systemctl status kubelet
````
