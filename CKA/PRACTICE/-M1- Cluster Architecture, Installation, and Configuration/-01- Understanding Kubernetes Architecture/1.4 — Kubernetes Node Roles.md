## Description de la composition d'un `Node` : 

Un `node` peut être une machine virtuelle ou physique, selon le cluster, il fournit le hardware pour faire tourner `k8s`.

### - `Pod`:
- Plus petite unité de `Kubernetes`, Chaque `pod` est géré par le `control plane` et contient les services nécessaires pour exécuter le `pods`.

### - `Control plane` :
- C'est l'orchestrateur d'un ou plusieurs `node`

### - `Namespace` :
- Est une cloison logique dans un cluster, ils servent à : `Isoler`, `eviter les colision de nom` (Le nom est unique par namespace, pas par cluster.), `RBAC` (Droits), `Quotas de ressources`

### - `Service ` :
- A le role d'un reverse proxy , comme les container changer d'IP à chaque création le `Service` est la comme adresse Ip unique et redistribut au bon container la requete.
Il peut avoir 4 rôles : `Cluster IP`, `Node Port`, `LoadBalancer`, `External Name`.

### - `Ingress` :
- Est la porte d'entrée qui gére le traffic depui l'exterieur du cluster vers les différentes parties
