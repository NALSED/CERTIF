# Kubeadm init paramétrable

---

- Il est possible d'utiliser `kubeadm init` avec des options pour faciliter l’installation => Voir [ICI](https://kubernetes.io/docs/reference/setup-tools/kubeadm/kubeadm-init/#options)

- Ou utiliser un fichier yaml de configuration avec la commande (c'est un template)
````
# Voir le template
sudo kubeadm config print init-default

# Utiliser ce template
sudo kubeadm config print init-default > config.yaml
# Puis
vim config.yaml
````

- Changer les options voulues et lancer `init` (être dans le dossier où se trouve le fichier de configuration)
````
kubeadm init --config=config.yaml
````
