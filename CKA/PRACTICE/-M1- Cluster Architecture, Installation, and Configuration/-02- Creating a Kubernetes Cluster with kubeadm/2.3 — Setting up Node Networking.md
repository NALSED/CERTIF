## Configuration réseau Node

---

`[NOTE]`

- Communication :

-1- Node <=> Node : `Réseau Physique`

-2- Extérieur <=> Service : `Kubernetes Service`

-3- Pod <=> Service : `Kubernetes Service`

-4- Pod <=> Pod : `Network Plugin`

-5- Container <=> Container : `Pod`

---

   - `Calico`
   - `Flannel`
   - `Multus`
   - `Weave`
