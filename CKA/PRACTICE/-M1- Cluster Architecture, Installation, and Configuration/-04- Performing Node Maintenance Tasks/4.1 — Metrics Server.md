## Metrics Server

- Composant qui collecte les `métriques CPU/RAM` des `nodes` et `pod`.

- Il sert aussi de base pour l'autoscaling (HPA — [Horizontal Pod Autoscaler](https://kubernetes.io/docs/concepts/workloads/autoscaling/horizontal-pod-autoscale/)), qui a besoin de ces métriques pour décider quand scaler un déploiement

---

`[NOTE]`

- Le metric server n'est pas toujours installé par `kubeadm`
