## Cluster Node Upgrades

---

`[NOTE]`

=== Exemple Version ===
1.30.7

- 1 => Majeur
- 30 => Mineur
- 7 => Patch

- `Kubernetes` peut être mis à niveau depuis une version vers une autre version mineure en respectant l'ordre :

- Il est possible de passer de 1.30 => 1.31 mais pas 1.30 => 1.32

---

<summary>
<h2>
 CONTROLE NODE
</h2>
</summary>

### === Procédure mise à Niveau `Control plane` ===

[DOC_OFFICIELLE UPGRADE MASTER NODE](https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/kubeadm-upgrade/)

`-1-` Modifier le fichier `/etc/apt/sources.list.d/kubernetes.list`

`-2-` Trouver le dernière version pour `kubeadm`

`-3-`Upgrade le `control plane nodes`

   `-3.1-` upgrade `kubeadm`

   `-3.2-` `Drain` le node à Upgrade

   `-3.3-` upgrade `kubelet` et `kubectl`

   `-3.4-` `uncordon` le node 
   
---

### `-1-` Modifier le fichier `/etc/apt/sources.list.d/kubernetes.list`
````
sudo vim /etc/apt/sources.list.d/kubernetes.list

# Version actuelle
deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.36/deb/ /
````
````
# Changer pour la version suivante:
deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.37/deb/ / 
````

### `-2-` 
````
sudo apt update
sudo apt-cache madison kubeadm
````

- Ici :
````
kubeadm | 1.37.0-1.1 | https://pkgs.k8s.io/core:/stable:/v1.37/deb  Packages
````


## `-3-` `Upgrade control plane`

### `-3.1-` Upgrade Kubeadm

`[NOTE]`
apt-mark bloque les MAJ automatique.
````
sudo apt-mark unhold kubeadm && \
sudo apt-get update && sudo apt-get install -y kubeadm='1.37.0-1.1' && \
sudo apt-mark hold kubeadm
````

- Vérifier la version
````
kubeadm version
```` 

- Ici
````
kubeadm version: &version.Info{Major:"1", Minor:"37" ......
````


- Donne une vue d'ensemnle du cluster
````
sudo kubeadm upgrade plan
````

- Upgrade kubeadm
````
sudo kubeadm upgrade apply v1.37.0
````

### `-3.2-` `Drain` le node à Upgrade (depuis master)
````
kubectl drain <node-to-drain> --ignore-daemonsets
````

### `-3.3-` upgrade `kubelet` et `kubectl`
````
sudo apt-mark unhold kubelet kubectl && \
sudo apt-get update && sudo apt-get install -y kubelet='1.37.0-1.1' kubectl='1.37.0-1.1' && \
sudo apt-mark hold kubelet kubectl
````

- Restart kubelet
````
sudo systemctl daemon-reload
sudo systemctl restart kubelet
````


### `-3.4-` `uncordon` le node (depuis master)
````
kubectl uncordon <node-to-uncordon>
````

### === Procédure mise à Niveau `Worker node` ===

[DOCUMENTATION OFFICIELLE UPGRADE WORKERS NODE](https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/upgrading-linux-nodes/)

`-3-` upgrade `kubeadm`

`-4-` `Drain` le node à Upgrade

`-5-` upgrade `kubectl`

`-6-` `uncordon` le node 
   
---

````
sudo vim /etc/apt/sources.list.d/kubernetes.list

# Version actuelle
deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.36/deb/ /

````

deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.37/deb/ /

`-2-` update `kubelet` et `kubeadm`
