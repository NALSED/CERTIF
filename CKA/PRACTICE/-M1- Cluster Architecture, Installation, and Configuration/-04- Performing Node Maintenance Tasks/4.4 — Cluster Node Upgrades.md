## Cluster Node Upgrades

---

`[NOTE]`

=== Exemple Version ===
1.30.7

- 1 => Majeur
- 30 => Mineur
- 7 => Patch

- `Kubernetes` peut être mis à niveau depuis une version vers une autre version mineure en respectant l'ordre :

- Il est possible de passer de 1.30 => 1.31 mais pas 1.30 => 1.32

---

### === Procédure mise à Niveau ===

- Cette procédure est détaillée ici => [DOC_OFFICIELLE](https://kubernetes.io/docs/tasks/administer-cluster/kubeadm/kubeadm-upgrade/)

`-1-` Modifier le fichier `/etc/apt/sources.list.d/kubernetes.list`

`-2-` Trouver le dernière version pour `kubeadm`

`-3-`Upgrade le `control plane nodes`

   `-3.1-` upgrade `kubeadm`

   `-3.2-` `Drain` le node à Upgrade

   `-3.3-` upgrade `kubelet` et `kubectl`

   `-3.4-` `uncordon` le node 
   
---

### `-1-` Modifier le fichier `/etc/apt/sources.list.d/kubernetes.list`
````
sudo vim /etc/apt/sources.list.d/kubernetes.list

deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.36/deb/ /

# Changer pour la version suivante:
deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.37/deb/ / 
````

### `-2-` 
````
sudo apt update
sudo apt-cache madison kubeadm
````

## `-3-` `Upgrade control plane`

### `-3.1-` Upgrade Kubeadm


````
# replace x in 1.37.x-* with the latest patch version
sudo apt-mark unhold kubeadm && \
sudo apt-get update && sudo apt-get install -y kubeadm='1.37.x-*' && \
sudo apt-mark hold kubeadm
````

- Vérifier la version
````
kubeadm version
```` 

- Vérification si le cluster peux être Upgrade
````
sudo kubeadm upgrade plan
````

- Upgrade kubeadm
````
# replace x with the patch version you picked for this upgrade
sudo kubeadm upgrade apply v1.37.x
````

### `-3.2-` `Drain` le node à Upgrade
````
kubectl drain <node-to-drain> --ignore-daemonsets
````

### `-3.3-` upgrade `kubelet` et `kubectl`
````
# replace x in 1.37.x-* with the latest patch version
sudo apt-mark unhold kubelet kubectl && \
sudo apt-get update && sudo apt-get install -y kubelet='1.37.x-*' kubectl='1.37.x-*' && \
sudo apt-mark hold kubelet kubectl
````

- Restart kubelet
````
sudo systemctl daemon-reload
sudo systemctl restart kubelet
````


### `-3.4-` `uncordon` le node 

kubectl uncordon <node-to-uncordon>
