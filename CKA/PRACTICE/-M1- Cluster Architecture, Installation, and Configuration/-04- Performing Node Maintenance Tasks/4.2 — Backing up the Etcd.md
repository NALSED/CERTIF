## Sauvegarde de `etcd`

---
- `etdc` est la `db` de kubernetes, elle contient toutes les ressources du cluster, son importance est donc `critique`.

- L'utilitaire `etcdctl` n'est pas inclue dans le package standart de kubetools .
````
sudo apt install etcd-client
````

### ⚠️ Pour utiliser `etcdctl`, il faut spécifier: ⚠️
- `endpoint`
- `cacert`
- `cert`
- `Key`

- Utiliser `ps` pour trouver ces valeurs :
````
ps aux | grep etcd
````
