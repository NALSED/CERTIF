## High Availability 

---

`[NOTE]`

- Dans `kubernetes` la `H.A` est utilisé en cas de chute du node `controle plane`, en effet si ce node tombe, impossible de manager le cluster .

- Plusieurs options sont possible pour implémenter de la `H.A`:
   
   - -1- `Stacked control plane nodes` => Plusieurs controle plane nodes `mutualise etcd`

   - -2- External etcd cluster => `Etcd` est séparé par cotrole plane node.
