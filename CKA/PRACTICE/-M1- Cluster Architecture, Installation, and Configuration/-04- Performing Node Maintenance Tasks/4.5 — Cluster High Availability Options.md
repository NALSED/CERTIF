## High Availability 

---

`[NOTE]`

- Dans `kubernetes` la `H.A` est utilisé en cas de chute du node `controle plane`, en effet si ce node tombe, impossible de manager le cluster .

- Pour ce faire il faut mettre en place la `H.A` ainsi qu'un `load balancer` (load balancer qui sera installé par script depuis le github de [sander van vugt](https://github.com/sandervanvugt/cka))
