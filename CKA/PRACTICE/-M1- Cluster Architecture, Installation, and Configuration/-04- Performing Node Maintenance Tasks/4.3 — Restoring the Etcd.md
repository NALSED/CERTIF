## Restauration de BackUp `etcd`

---

### === Procédure de restauration de etcd === 

`-1-` `Déplacer` les fichiers `.yaml` de `/etc/kubernetes/manifests/`

`-2-` `Renommer` le `dossier` de `/var/lib/etcd` => `/var/lib/etcd-old`

`-3-` `Restaurer` le BackUp de `etcd`

`-4-` `Replacer` les fichiers `.yaml` dans `/etc/kubernetes/manifests/`

`-5-` Vérification avec `crictl`

---

### `-1-` Déplacer les fichiers des Static Pods de `/etc/kubernetes/manifests/`
````
sudo mv /etc/kubernetes/manifests/*.yaml /etc/kubernetes/
````

### `-2-` Renommer le dossier `/var/lib/etcd`
````
sudo mv /var/lib/etcd /var/lib/etcd-old
````

### `-3-` Restauration
````
sudo etcdctl snapshot restore /tmp/EtcdBackUp.db --data-dir /var/lib/etcd
````

### `-4-` Replacer les fichiers .yaml dans `/etc/kubernetes/manifests/`
````
sudo mv /etc/kubernetes/*.yaml /etc/kubernetes/manifests/
````

### `-5-` Vérification
````
crictl ps
````
