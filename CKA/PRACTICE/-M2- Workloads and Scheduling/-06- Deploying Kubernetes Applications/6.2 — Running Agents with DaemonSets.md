## DaemonSet dans k8s

---

- La création de `daemonset` dans kubernetes permet de déployer (par defaut) le même container sur chaque `woker node` simultanément.

- Il est bien entendu possible de le déployer sur le / les `control plane` ou cibler un / des node précisement.

- Le dameonset se déploie de maniére dynamique, si à l'avenir des node venais à être ajoutés au cluster, le damonset se déploie automatiquement sue ces derniers sans intervention humaine. 

=== UseCase ===

- Collecte de logs (FluentBit / Promtail => Loki / Elastisearch)

- Gestion ressources ( Prometheus Node Exporter )

- Gestion réseau : installation à l'ajout d'un node via daemonset calico / flannel ou autre.

- Sécurité  ( Falco )

--- 

- Création d'un fichier .yaml avec `--dry-run=client`
````
kubectl create deploy test-daemon --image=IMAGE --dry-run=client -o yaml > daemon.yaml
````

-  Changer `3` lignes

   - kind: Deployment => kind: DaemonSet
   - replicas: 1 => SUPPRIMER
   - strategy: {} => SUPPRIMER

````
apiVersion: apps/v1
kind: Deployment
metadata:
  labels:
    app: test-daemon
  name: test-daemon
spec:
  replicas: 1
  selector:
    matchLabels:
      app: test-daemon
  strategy: {}
  template:
    metadata:
      labels:
        app: test-daemon
    spec:
      containers:
      - image: nginx:latest
        name: nginx
        resources: {}
status: {}
````

- Déployer
````
kubectl apply -f daemon.yaml
````

- verrifier
````
 k get all
````
