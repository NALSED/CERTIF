## DaemonSet dans k8s

---

- La création de `daemonset` dans kubernetes permet de déployer (par defaut) le même container sur chaque `woker node` simultanément.

- Il est bien entendu possible de le déployer sur le / les `control plane` ou cibler un / des node précisement.

- Le dameonset se déploie de maniére dynamique, si à l'avenir des node venais à être ajoutés au cluster, le damonset se déploie automatiquement sue ces derniers sans intervention humaine.
