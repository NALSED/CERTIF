## **=== Bases du deployment dans k8s ===**

- La commande `kubectl create deployement` est la maniére standart de créer / lancer un caontainer dans kubernetes.

-  Le `deployment` garantie que le `pod` est lancé de maniére `scalable`.

-  Utilisation de la ressource `ReplicaSet` pour manager la scalabilité

-  Possibilité de gérer les `MAJ` d'un `container` avec RollinUpdate.

---

- Cette partie est un rafraichissement des commandes et possibilités, vue dans la certification `CKAD`.

### - Déployer un pods avec 3 replicaset
````
kubectl create deployment deploy-test --image=nginx:latest --replicas=3
````


---

### Augmenter les réplicats
````
kubectl scale deployment NAME DEPLOYMENT --replicas=NUMBER
````

---

### Faire une MAJ
````
kubectl set-image  deployment IMAGE
````

### Supprimer un deployment
````
kubectl delete deployment NAME DEPLOYMENT
````
