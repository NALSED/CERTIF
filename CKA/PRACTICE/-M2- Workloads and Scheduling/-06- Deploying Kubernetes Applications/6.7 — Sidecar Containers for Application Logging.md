## Side car containers => Journalisation Logs.

---

- La norme est de créer un pod pour une tache précise, mais dans certain cas il est nécessaire de créer un container supplémentaire, afin de modifier l'état du premier.

- Cas Spécifiques :

   - `Sidecar` : Ajoutes des fonctionnalités supplémentaires au container principal.
   -  `Ambassador` : Utilisé comme proxy pour connecter des containers externes.
   -  `Adapter` : Normalise les sortie du container principal.

- La solution pour pouvoir "connecter" 2 container, est de passer par un stockage partégé, un container écris, l'autre lit.

- 

---

**=== Exemple ===**

### `-1-` Créer un `EmptyDir`

[https://kubernetes.io/docs/concepts/storage/volumes/#emptydir-configuration-example](https://kubernetes.io/docs/concepts/storage/volumes/#emptydir-configuration-example)


`- 1.1` Créer le fichier pour `busy box`
````
vim test-sidecar.yaml
````
````
apiVersion: v1
kind: Pod
metadata:
  name: test-sidecar
spec:
  containers:
  - image: busybox
    name: test-busy
    volumeMounts:
    - mountPath: /messages
      name: cache-volume
  volumes:
  - name: cache-volume
    emptyDir:
      sizeLimit: 500Mi
````

`- 1.2` Créer un fichier test afin de récupérer une implémentation correct
````
kubectl run test --image=busybox --dry-run=client -o yaml -- sh -c "echo hello > /message/"
````

`- 1.3` Récupérer la sortie
````
  - args:
    - sh
    - -c
    - echo hello > /messages/myfiles
````

`- 1.4` Ajouter au ficier .yaml de `busy box`
````
vim test-sidecar.yaml 
````
````
apiVersion: v1
kind: Pod
metadata:
  name: test-sidecar
spec:
  containers:
  - image: busybox
    name: test-busy
    volumeMounts:
    - mountPath: /messages
      name: cache-volume
    args:
    - sh
    - -c
    - echo hello > /messages/index.html; sleep 3600

  - image: nginx
    name: test-webserver
    volumeMounts:
    - mountPath: /usr/share/nginx/html
      name: cache-volume
  volumes:
  - name: cache-volume
    emptyDir:
      sizeLimit: 500Mi
````
````
kubectl apply -f test-sidecar.yaml
````
### `-2-` Test
````
kubectl exec test-sidecar -c test-webserver -- curl -s localhost
````
