 ## Scalabilité.

 ---

 - Dans kubernetes la scalabilité peux être gérer manuellement via : 
````
kubectl scale deploy NAME --replicas=NUMBER
````

- Ou avec l'utilisation de scalabilité via `horizontal pods`
````
# Dans les flag on peux aussi ajouter des ressource CPU et RAM
kubectl autoscale deploy NAME --min=NUMBER --max=NUMBER
````

- Pour voir les pods créés via cette technique utiliser
````
kubectl get hpa

# hpa => Horizontal Pod Autoscaler
````
