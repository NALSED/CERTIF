## StatefulSet

---

- Cette fonctionnalité gère les besoins `stateful` des Pods. Le `stateless` est géré par `Deployment`.

=== Skills StatefulSet ===

- `PVC propres` : chaque Pod reçoit son propre volume, créé automatiquement depuis le modèle `volumeClaimTemplates`.

- `Noms fixes` : le nom (`web-0`) et le volume attribué ne changent pas au redémarrage.

- `DNS` : via un Service headless (`clusterIP: None`) et `serviceName`, le nom fixe suit l'IP à chaque redémarrage. On joint ainsi un Pod précis par son hostname (`web-0.mon-service`).

- `Ordre par ID` : les Pods démarrent de 0 à N, un par un, et s'arrêtent dans l'ordre inverse. Le nœud principal est ainsi prêt avant les réplicas.

---

**=== Exemple ===**

- Ici l'exemple portera sur un fichier .yaml trouvé sur [https://kubernetes.io/fr/docs/concepts/workloads/controllers/statefulset/](https://kubernetes.io/fr/docs/concepts/workloads/controllers/statefulset/)

- Pour definir un état Stateful dans Kubernetes des lignes sont obligatoires pour géner un êtat `Statefull` :

  **#1#** `clusterIP` : None` => Rend le service `Headless`
   
  **#2#** `serviceName` : "NAME" => Nom exact du Headless Service
 
   **#3#** `name` : NAME => Doit correspondre au name sous volumeClaimTemplates
 
   **#4#** `volumeClaimTemplates` : => Génère un PVC par Pod (www-web-0, www-web-1...)
 
  **#5#** - `storageClassName` : "standard"


````
apiVersion: v1
kind: Service
metadata:
  name: nginx
  labels:
    app: nginx
spec:
  ports:
  - port: 80
    name: web
  clusterIP: None
  selector:
    app: nginx
---
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: web
spec:
  selector:
    matchLabels:
      app: nginx # doit correspondre à .spec.template.metadata.labels
  serviceName: "nginx"
  replicas: 3 # est 1 par défaut
  template:
    metadata:
      labels:
        app: nginx # doit correspondre à .spec.selector.matchLabels
    spec:
      terminationGracePeriodSeconds: 10
      containers:
      - name: nginx
        image: registry.k8s.io/nginx-slim:0.8
        ports:
        - containerPort: 80
          name: web
        volumeMounts:
        - name: www
          mountPath: /usr/share/nginx/html
  volumeClaimTemplates:
  - metadata:
      name: www
    spec:
      accessModes: [ "ReadWriteOnce" ]
      storageClassName: "my-storage-class"
      resources:
        requests:
          storage: 1Gi
````
