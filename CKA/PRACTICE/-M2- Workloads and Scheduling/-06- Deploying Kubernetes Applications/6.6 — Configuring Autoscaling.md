## Gestion AutoScaling

---

- La gestion de cette fonctionnalité se fait via un ressource API à part entière : `Horizontal Pod Autoscaler` ou hpa.

- `HPA` se base sur le `Metric server` afin de prendre des mesures en fonction de la charge, et des ressources disponible.  Pour l'installation du Metric server voir => [-4.1- Metric Server.md](https://github.com/NALSED/CERTIF/blob/main/CKA/PRACTICE/-M1-%20Cluster%20Architecture%2C%20Installation%2C%20and%20Configuration/-04-%20Performing%20Node%20Maintenance%20Tasks/4.1%20%E2%80%94%20Metrics%20Server.md)

---

**=== Exemple ===**

`-1-` Créer un deployment
````
kubectl create deployment test-autoscale --image=nginx:latest 
````
````
kubectl get pods

# Sortie
 NAME                              READY   STATUS    RESTARTS      AGE
test-autoscale-55d9bcd955-882vv   1/1     Running   0             11s
````

`-2-` Appliquer l'autoscaler (Avec max CPU)
````
kubectl autoscale deployment test-autoscale --min=2 --max=4 -cpu=60%

````
````
kubectl get hpa

# Sortie
sednal@k8s-master:~$ k get  hpa
NAME             REFERENCE                   TARGETS              MINPODS   MAXPODS   REPLICAS   AGE
test-autoscale   Deployment/test-autoscale   cpu: <unknown>/60%   2         8         2          96s
````


`-3-` Modifier le délai de check pour la charge.

- 2 Possibilité :

   - `-1-` Passer par `/etc/kubernetes/manifests/kube-controller-manager.yaml`, et ajouter la ligne `--horizontal-pod-autoscaler-downscale-stabilization duration   [DOC](https://kubernetes.io/docs/reference/command-line-tools-reference/kube-controller-manager/#options). ⚠️ La configuration s'applique à tout le cluster. ⚠️
 
   - `-2-` Pour une gestion plus fine utiliser la partie `spec.behavior.scaleDown.stabilizationWindowSeconds` du .yaml du deploiement concerné
     

---

### `-1-`
````
sudo vim /etc/kubernetes/manifests/kube-controller-manager.yaml  
````
````
spec:
  conttainers:
  -command:
    -kube-controler-manager
    - --horizontal-pod-autoscaler-downscale-stabilization=TEMPS
````

### `-2-`

[DOC](https://kubernetes.io/docs/concepts/workloads/autoscaling/horizontal-pod-autoscale/#stabilization-window)

````
kubect edit hpa test-autoscale
````
````
spec:
  behavior:
    scaleDown:
      stabilizationWindowSeconds: 300
````
