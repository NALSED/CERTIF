 ## Manage Applications avec Helm.

 ---

 - Il est possible de créer des fichier de `values.yaml` personalisés et de les appliquer lors de l'installation.

 - Helm permet de faire les mise à jours des images déployées.


---

### **=== Fichier `values.yaml` personnalisé ===**

`[RAPPEL]`
 - En installant via `helm Chart` il est possible d'utiliser les fichier de configurations `values.yaml`, pour plus d'informaation sur la paire clé : valeur
==> [https://artifacthub.io/](https://artifacthub.io/)

- utilisation de `helm install` pour appliquer un fichier de configuration personnalisé.

- Trouver le repo
````
helm repo list

helm search repo bitnami
````

- Générer le fichier de `values.yaml` personalisées
````
vim values.yaml
````

- Installer l'image
````
helm install repo-apache bitnami/apache --values values.yaml
````

---

### **=== Mise à jour via Helm ===**

`[NOTE]`

- Un `Helm Chart` est un package installé à partir d'un dépot Helm, c'est le fichier originel.
- Une installation Helm est une instance installé de ce package, en d'autre therme , helm créé une release à chaque install du'un package(versioning).

- Il est donc possible de revenir via :

- Historique
````
helm history mon-apache

# Sortie
REVISION  UPDATED       STATUS      CHART           DESCRIPTION
1         ...           superseded  apache-10.1.0   Install complete
2         ...           superseded  apache-10.2.0   Upgrade complete
3         ...           deployed    apache-10.2.0   Upgrade complete
````

- RollBack
````
helm rollback mon-apache 1
````

- Pour mettre à jour le repo
````
helm repo update
````

- Un paquet en particulier
````
  helm upgrade NOM_RELEASE REPO/CHART
````
