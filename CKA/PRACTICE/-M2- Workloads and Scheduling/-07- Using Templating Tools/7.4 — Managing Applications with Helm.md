 ## Manage Applications avec Helm.

 ---

 - Il est possible de créer des fichier de `values.yaml` personalisés et de les appliquer lors de l'installation.

 - Helm permet de faire les mise à jours des images déployées.


---

### **=== Fichier `values.yaml` personnalisé ===**

`[RAPPEL]`
 - En installant via `helm Chart` il est possible d'utiliser les fichier de configurations `values.yaml`, pour plus d'informaation sur la paire clé : valeur
==> [https://artifacthub.io/](https://artifacthub.io/)

- utilisation de `helm install` pour appliquer un fichier de configuration personnalisé.

- Trouver le repo
````
helm repo list

helm search repo bitnami
````

- Générer le fichier de `values.yaml` personalisées
````
vim values.yaml
````

- Installer l'image
````
helm install repo-apache bitnami/apache --values values.yaml
````
