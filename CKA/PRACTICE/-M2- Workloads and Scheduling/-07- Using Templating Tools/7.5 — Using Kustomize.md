## Kustomize

---

- Kustomize permet d'appliquer des modification sur un déploiment par environement.

**=== Exemple ===**

- Environement :
   - dev
   - staging
   - prod

- On souhaite que le déploiement des application via Helm soit différente en terme de CPU, replicas, ou alors donner un préfixe, namespace ou label.

- (Pour plus d'information sur les possibilités [https://kubernetes.io/docs/tasks/manage-kubernetes-objects/kustomization/](https://kubernetes.io/docs/tasks/manage-kubernetes-objects/kustomization/))

## **=== Marche à suivre ===**

### `-1-` Créer la base

`- 1.1` Créer le dossier
````
mkdir -p kustomize/base
````

`- 1.2` Créer le fichier de Base pour l'application (Ici nginx)
````
vim kustomize/base/deployment.yaml
````
````
# base/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 1
  template:
    spec:
      containers:
      - name: web
        image: nginx:1.25
````

`- 1.3` Créer le fichier `kustomize` pour la base 
````
vim /kustomize/base/kustomize.yaml 
````
````
# base/kustomization.yaml
resources:
  - deployment.yaml
  - service.yaml
````

**A ce stade** Voici l'arborécence du projet de base.
````
kustomize/
└── base/
    ├── deployment.yaml      # replicas: 1, image par défaut
    ├── service.yaml
    └── kustomization.yaml
````

### `-2-` Création d'overlay

- Création d'overlay (modification du projet base) un par environement (dev, staging, prod, etc...).

`- 2.1` Créer le dossier ici => prod.
````
mkdir -p kustomize/overlays/prod
````

`- 2.2` Créer le fichier kustomize.yaml
````
# ../../base reviens dans /base
resources:
  - ../../base
patches:
# utilisation du fichier patch-replicas.yaml pour modifier le nombre de réplicas de base.
  - path: patch-replicas.yaml
    target:
      kind: Deployment
      name: web
````

`- 2.3` créer le fichier `patch-replicas.yaml`
````
vim overlays/prod/patch-replicas.yam
````
````
- op: replace
  path: /spec/replicas
  value: 5
````

### `-3-` Vérrif du fichier
````
kubectl kustomize overlays/prod/
````

### `-4-` Déploiement
````
kubectl apply -k overlays/prod/
````


---

### **=== Arborécence type ===**
````
kustomize/
├── base/
│   ├── deployment.yaml      # replicas: 1, image par défaut
│   ├── service.yaml
│   └── kustomization.yaml
│
└── overlays/
    ├── dev/
    │   ├── kustomization.yaml
    │   └── patch.yaml        # replicas: 1, image tag "dev"
    │
    ├── staging/
    │   ├── kustomization.yaml
    │   └── patch.yaml        # replicas: 2
    │
    └── prod/
        ├── kustomization.yaml
        └── patch.yaml        # replicas: 5, limits CPU/mem plus hauts
````
