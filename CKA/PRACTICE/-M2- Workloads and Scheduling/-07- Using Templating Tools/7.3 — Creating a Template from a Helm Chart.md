## Template Helm Chart

---

- Exemple d'utilisation de déploiment via `Helm` + `Chart` + `values.yaml`

---

- Ici utilisation de l'application `Argo CD`

- Utilisation de la commande `helm template` = `--dry-run=client`

`-1-` Récupération du repo
````
helm repo add argo-repo https://argoproj.github.io/argo-helm
````

`-2-` Update
````
helm repo update
````

`-3-` Rechercher la bonne image
````
helm search repo argo/argo-cd
````

`-4-` Créer le template
````
helm template test-template argo/argo-cd --version7.7.15 > template-argo.yaml
````

- Le template ainsi créé donne toutes les resources dont on à besoin afin de faire tourner argo-cd

- De plus on peux implémenter les variables avec le fichier `value.yaml`


`-5-` Générer le fichier `value.yaml`
````
helm show values argo/argo-cd > values.yaml
````

- A présent on peux changer ces valeur et elle seront appliqué sur le fichier yaml de argo-cd

`-6-` Lier le fichier yaml de l'image =>  values.yaml
````
helm template  test-template argo/argo-cd -f values.yaml > test-final-argo.yaml
````

`-7-` Déployer 
````
kubectl apply -f test-final-argo.yaml
````
