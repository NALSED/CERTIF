## Helm Packet Manager

---

**=== Présentation ===**

- Helm est le gestionnaire de paquet (Chart) pour Kubernetes.

- Helm permet, en autre :
   - Créer des `template` de YAML avec variables
   - Avec `une seul commande` tout déployer (Deployment, Service, ConfigMap, Secret...)
   - Le fichier values.yaml `centralise la config`.
   - `Rollback` intégré
   - `Historique` des realeses

- Helm est un gestionnaire de paquet, il est utilisé avec Chart.

- `Chart` gére le template ainsi que les valeurs, pour le déploiement de chaque objet dans kubernetes.

 ---

### `-1-` Installation Helm

`- 1.1` récupération du binaire de helm [https://github.com/helm/helm/releases](https://github.com/helm/helm/releases)
````
curl -L -O https://get.helm.sh/helm-v4.3.0-linux-amd64.tar.gz
````

`- 1.2` Décompressé et déplacer
````
 tar xvf helm-v4.3.0-linux-amd64.tar.gz

sudo mv linux-amd64/helm /usr/local/bin  
````

### `-2-` Utilisation de Helm

`- 2.1` Commande Basique
````
helm install kubernetes-dashboard kubernetes-dashboard/kubernetes-dashboard

# Explication
helm install #[1] #[2]/#[3]

#[1] Nom du repo local
#[2] Nom de l'application à installer
#[3] Nom du repo
````


`- 2.2` Importer un repo Chart en local
````
# importer
helm repo add bitnami https://charts.bitnami.com/bitnami

# Update
helm repo update

# Recherche / lister image installer
helm search repo REPO-NAME
helm list

# Installer
helm install NAME REPO-NAME/IMAGE-NAME

# Obtenir des info sur un Chart
helm show all REPO/IMAGE
````
