## LimitRange 

[https://kubernetes.io/docs/concepts/policy/limit-range/](https://kubernetes.io/docs/concepts/policy/limit-range/)

---


- `LimitRange` est u objet qui sert à définir les **ressources matériel** qu'un `pods` / `container` peuvent utiliser dans un `Namespace`.

---

`=== Exemple ===`
````
apiVersion: v1
kind: LimitRange
metadata:
  name: cpu-resource-constraint
  namespace: cpu-charge .................................... Le LimitRange s'appliquera uniquement sur CE namespace
spec:
  limits:
  - default: # this section defines default limits
      cpu: 500m
    defaultRequest: # this section defines default requests
      cpu: 500m
    max: # max and min define the limit range
      cpu: "1"
    min:
      cpu: 100m
    type: Container
````
