## Quotas

[https://kubernetes.io/docs/concepts/policy/resource-quotas/#enabling-resource-quota](https://kubernetes.io/docs/concepts/policy/resource-quotas/#enabling-resource-quota)

- Le `Quotas` ressource à pour but de déterminer les ressources disponible pour la totalité d'un `namespace`.

- La création d'un objet Quotas sur un `namespace` doit **Obligatoirement** 'accompagner de l'une des deux options suivantes :
   - soit un `LimitRange` (automatique pour tous les Pods)
   - soit des `requests/limits` manuels dans chaque Deployment

### **Créer un `Quotas`**

- Deux façons possible

`-1-` **Ligne de commande** 

`- 1.1` Créer un `namespace`
````
kubectl create namespace test-quotas
````

`- 1.2` Créer un `quotas` pour le namespace `test-quotas-1`
````
kubectl create quota -h

kubectl create quota my-quota --hard pods=3,cpu=100m,memory=1G -n test-quotas
````

`- 1.3` Vérification
````
kubectl describe namespace test-quotas
````
````
Name:         test-quotas
Labels:       kubernetes.io/metadata.name=test-quotas
Annotations:  <none>
Status:       Active

Resource Quotas
  Name:     my-quota
  Resource  Used  Hard
  --------  ---   ---
  cpu       0     100m
  memory    0     1G
  pods      0     3

No LimitRange resource. ............ !!! PAS de LimiteRange !!!
````
 
---

`-2-` **Fichier `.yaml`**

`- 2.1` Créer un `namespace`
````
kubectl create namespace test-quotas-2
````

`- 2.2 Créer un quotas`

[https://kubernetes.io/docs/concepts/policy/resource-quotas/#viewing-and-setting-quotas](https://kubernetes.io/docs/concepts/policy/resource-quotas/#viewing-and-setting-quotas)

````
cat <<EOF > test-quotas-2.yaml
apiVersion: v1
kind: ResourceQuota
metadata:
  name: compute-resources
spec:
  hard:
    pods: "1"
    cpu: "500m"
    memory: "2Gi"
EOF    

````

`- 2.3` Appliquer au namespace `test-quotas-2`
````
kubectl apply -f ./test-quotas-2.yaml --namespace test-quotas-2
````

### **Sans `LimitRange` / `Quotas sur deployment`** 

- Le `Déploiement` est il opérationnel. 
````
kubectl get all -n test-quotas
````
````
NAME                            READY   UP-TO-DATE   AVAILABLE   AGE
deployment.apps/deploy-quotas   0/5     0            0           82s

NAME                                       DESIRED   CURRENT   READY   AGE
replicaset.apps/deploy-quotas-58884c9647   5         0         0       82s
````

- On peux voir ici que le déploiement n'a pas eu lieu

- `Pourquoi`
````
kubectl describe -n test-quotas rs deploy-quotas-58884c9647
````
````
 Type     Reason        Age                  From                   Message
  ----     ------        ----                 ----                   -------
  Warning  FailedCreate  6m44s                replicaset-controller  Error creating: pods "deploy-quotas-58884c9647-72w4j" is forbidden: failed quota: my-quota: must specify cpu for: nginx; memory for: nginx
````

### ⚠️ Cela viens du fait que le deployment ne sait pas les limites de ressources qui lui sont alloué, maintenant obligatoire avec l'ajout d'un `Quotas` dans le namespace⚠️

````
Quota CPU/memory sur le namespace
   → chaque Pod DOIT avoir requests/limits définis
   → soit manuellement dans le Deployment
   → soit automatiquement via un LimitRange (injecté par l'admission controller)
````


### Avec Ajout `requests/limits` au deployement.

- Ajout via `kubectl set resource`
````
kubectl set resources deployment deploy-quotas \
  --requests=cpu=50m,memory=128Mi \
  --limits=cpu=100m,memory=256Mi \
  -n test-quotas
````

- `Test`
````
NAME                                       DESIRED   CURRENT   READY   AGE
replicaset.apps/deploy-quotas-58884c9647   0         0         0       42m <=== SANS requests/limits (bloqué)
replicaset.apps/deploy-quotas-6d68d99fc5   4         3         3       13m <=== AVEC requests/limits définis sur le Deployment (fonctionne)
````

 Yaml

</summary>

- créer un namespace
````
kubectl create namespace test-quotas
````


- Pour éviter des probléme de configuration éditer un fichier .yaml (Voir Doc Kubernetes)
````
vim quotas-limitrange.yaml
````
````
---
apiVersion: v1
kind: ResourceQuota
metadata:
  name: my-quota
  namespace: test-quotas
spec:
  hard:
    pods: "3"
    cpu: "300m"
    memory: "768Mi"
---
apiVersion: v1
kind: LimitRange
metadata:
  name: my-limitrange
  namespace: test-quotas
spec:
  limits:
  - type: Container
    default:
      cpu: 100m
      memory: 256Mi
    defaultRequest:
      cpu: 50m
      memory: 128Mi
````

- Appliquer
````
kubectl apply -f quotas-limitrange.yaml
````
